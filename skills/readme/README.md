# README da Aplicação

Skill para criar ou atualizar o README de uma aplicação conforme os arquivos e comandos reais do projeto.

## Instalação pelo CLI

```bash
npm install --global @jsndev/devskill
devskill-cli install readme
```

O CLI consulta o catálogo no GitHub e instala a skill para os dois agentes. Use `--host codex` ou `--host claude` para escolher apenas um. Inicie uma nova sessão do agente após instalar.

## Uso

Invoque `$devskill-readme` no Codex ou `/devskill_readme` no Claude Code e peça para criar ou atualizar o README do projeto.
