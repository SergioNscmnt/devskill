# Code review

Review the requested diff, commit, branch, or files.

1. Inspect the complete change and the surrounding code.
2. Identify concrete defects, regressions, security risks, and missing tests.
3. Prioritize findings by severity.
4. For every finding, include the affected file and line, the impact, and a suggested correction.

If no defects are found, state that explicitly and mention any remaining testing gaps.
