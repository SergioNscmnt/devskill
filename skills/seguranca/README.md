# Segurança da Aplicação

Skill para revisar e proteger dados, credenciais e configurações de uma aplicação.

## Instalação pelo CLI

```bash
npm install --global @jsndev/devskill
devskill-cli install seguranca
```

O CLI consulta o catálogo no GitHub e instala a skill para os dois agentes. Use `--host codex` ou `--host claude` para escolher apenas um. Inicie uma nova sessão do agente após instalar.

## Uso

Invoque `$devskill-seguranca` no Codex ou `/devskill_seguranca` no Claude Code e peça uma revisão de segurança ou uma correção específica.
